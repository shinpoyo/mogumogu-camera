# もぐもぐカメラ

カメラに映った口の動きに反応して、すこしずつ演出がすすんでいく子ども向けの
ブラウザアプリです。ぜんぶ食べると、えらんだテーマに応じたお祝いが起こります。

- 🚀 **ロケット** — 燃料がたまり、画面まんなかで発射する
- 🍱 **おべんとう** — マスがおかずで埋まる
- 👸 **おひめさま** — 身につけるものが増え、最後にドレスアップへんしんする
- 🚓 **パトロール** — ランプが灯り、主役がパトロールに出発する

設定パネルの「えんしゅつ」で切り替えられます。

外部ライブラリなし・ビルド不要。ES モジュールで書かれた素の HTML / CSS / JS です。

## つかいかた

`index.html` をブラウザで開き、「カメラを つける」を押してカメラを許可します。

> カメラ API（`getUserMedia`）は安全なコンテキストでしか動きません。
> `file://` で直接開くとブラウザによっては動かないため、
> ローカルサーバ経由か HTTPS で開いてください。
>
> ES モジュール（`<script type="module">`）を使っているため、
> `file://` では import が動かないブラウザもあります。必ずサーバ経由にしてください。

```bash
python -m http.server 8099
```

そのあと `http://localhost:8099/` を開きます。

## そうさ

| したいこと | やりかた |
|---|---|
| えんしゅつを えらぶ | 設定パネルの「えんしゅつ」 |
| 口の位置を合わせる | 画面のわっかをドラッグ |
| わっかの大きさを変える | わっかの上で2本指ピンチ（PCはホイール、`+` / `-`） |
| 手動で1口すすめる | 右下の「たべた！」ボタン |
| 設定を開く | 右上の「設定」 |

## せってい

| 項目 | 内容 | 既定 |
|---|---|---|
| えんしゅつ | テーマ（ロケット／おべんとう／おひめさま／パトロール） | ロケット |
| なんくちで かんせい | 完了までの口数（2〜12） | 6 |
| うごきを みる | 口の動きの検知そのもののオン／オフ | オン |
| はんのう しやすさ | 検知のしきい値（1〜10、大きいほど反応する） | 5 |
| わっかの おおきさ | 検知範囲の直径（14〜60vmin） | 34 |
| おと / ほめる こえ | 効果音 / 音声読み上げ | オン |

設定とわっかの位置はブラウザに保存され、次回そのまま復元されます。
以前のバージョン（ロケット ON/OFF の1テーマ制）の設定も自動で引き継がれます。

**勝手に反応しすぎるとき**は「うごきを みる」をオフにして、
おうちのかたが「たべた！」を押す手動モードで使ってください。
検知を使いたい場合は「はんのう しやすさ」を下げるか、わっかを小さくすると落ち着きます。

## キャラクター画像の差し替え

「おひめさま」「パトロール」のテーマは、既定では絵文字で表示されます。
お手持ちの画像（正方形に近い透過PNG、目安256×256px）に差し替えたいときは、
[src/config.js](src/config.js) の `assets` にファイルパスを書くだけです。

```js
assets: {
  "patrol.hero": "./assets/hero.png",
  "princess.girl": "./assets/girl.png",
  "princess.crowned": "./assets/princess.png",
}
```

画像ファイルは `assets/` フォルダに置いてください（`.gitignore` 済みなので、
リポジトリには入りません）。既存のキャラクターの画像を使う場合は、
ご家庭など私的な範囲にとどめてください。

## ファイル構成

```
index.html          骨組みだけの HTML
styles/
  base.css          共通の見た目（カメラ・わっか・ボタン・パネル）
  themes.css         テーマごとの見た目
src/
  main.js           組み立て役。モジュールをつないで線を引くだけ
  config.js         差し替えたいものを1か所に（画像パス・おかず・ほめ言葉）
  core/             状態そのもの（設定の保存、進行状態、モジュール間の連絡）
  input/            カメラ映像から「ひとくち」を取り出す
  fx/               見せる道具（パーティクル・音・画面演出）
  ui/               操作（設定パネル、常設ボタン）
  themes/           テーマ本体。1テーマ = 1ファイル
```

各層の役割は [docs/設計書.md](docs/設計書.md) に、
「なぜこう分けたか」は [docs/作業履歴.md](docs/作業履歴.md) にあります。

## テーマを増やす

1. `src/themes/` にファイルを作り、`mount / unmount / build / progress / bite / celebrate / reset` を実装する
2. `src/themes/index.js` の配列に追加する
3. 見た目が必要なら `styles/themes.css` にセクションを足す

これだけで設定パネルの選択肢にも自動で出ます。既存のテーマやコアのモジュールは
一切変更しなくてよい設計です。詳しい約束ごとは
[src/themes/index.js](src/themes/index.js) の先頭コメントを参照してください。

## 動作環境

カメラと Web Audio、ES モジュールが使える最近のブラウザ
（iOS Safari / Android Chrome / PC Chrome）。
音声読み上げ（`speechSynthesis`）は非対応でも動きます。
`prefers-reduced-motion` を設定している場合は、揺れや点滅を抑えた表示になります。
