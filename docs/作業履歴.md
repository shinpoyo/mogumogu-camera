# 作業履歴

## 2026-08-18 「たべた！」ボタン常時表示・リングサイズ調整・ロケット演出

対象ファイル: `index.html`（単一ファイル構成）

### 1. 「たべた！」ボタンをすぐ押せるように

これまで手動判定ボタンは設定パネル（設定ボタン → パネルを開く）の中にしかなく、
反応しなかったときに2タップ必要だった。

- 画面右下に常時表示の丸ボタン `#biteBtn`（104×104px）を追加
- カメラ開始と同時に表示、タップで `manualBite()` を実行
- タップ時に黄色い波紋（`.tapped`）でフィードバック
- `touch-action:manipulation` でダブルタップズームを抑止
- 設定パネル内の「いま たべた！」も従来どおり残置（同じ処理を共有）

### 2. リングのサイズを調整可能に

リングの大きさは CSS の `34vmin` 固定、検知範囲の `ringR=.17` も別々のハードコードだった。
CSS 変数 `--ring-size` に一本化し、JS の `applyRingSize()` から両方を同期させる。

- CSS 変数 `--ring-size` を追加、`#ring` の幅・高さ・マージンを `calc()` で連動
- `ringR = ringVmin / 200` で検知 ROI の半径をリング表示と一致させる
- 変更手段は4通り
  - 設定パネルのスライダー「わっかの おおきさ」（14〜60vmin）
  - リング上での2本指ピンチ（`pointerdown/move` を `Map` で多点管理）
  - マウスホイール（PC用）
  - キーボード `+` / `-`（リングにフォーカス時）
- サイズ変更時は `prevGray=null; warm=0` で明るさ学習をやり直す（ROIが変わるため）
- 設定・リング位置を `localStorage`（キー `mogumogu-camera:v1`）に保存し次回復元

### 3. ロケット演出の追加

ひとくちごとに燃料が溜まり、完食で発射する演出を追加。

**燃料が溜まる段階**
- 画面左下に6段の燃料ゲージ `#gauge` とロケット `#ship` を配置
- ひとくちごとにセグメントが点灯、炎 `#flame` が 5px ずつ伸びて揺らめく
- 音: 既存のチャイムに加え、燃料が溜まる上昇音 `charge()`（sawtooth のスイープ）
- 小さな噴射パーティクルがロケット下から吹く
- 残り1マスになるとロケットが小さく上下に跳ねる（`.ready`）

**発射シーケンス**（`completeSequence()`、`later()` で全タイマーを管理）

| 時刻 | 内容 |
|---|---|
| 0.6s | 「おべんとう かんせい！」＋ファンファーレ＋音声 |
| 1.7 / 2.35 / 3.0s | カウントダウン 3・2・1（大きな数字＋電子音） |
| 3.65s | 「はっしゃ！」フラッシュ・画面シェイク・ロケット上昇・轟音・噴射／煙パーティクル・星の連続バースト |
| 5.3s | シェイク終了 |
| 6.3s | 「また あしたも たべようね」＋弁当箱とゲージをリセット |

**その他の演出強化**
- ひとくちごとにリングが波紋状に広がる（`.hit`）
- バーストのパーティクルに、そのとき埋まったおかずの絵文字が35%の確率で混ざる
- 発射の轟音 `rumble()`: ホワイトノイズ＋ローパスフィルタのスイープと低音サウを重ねて合成
- パーティクルに `kind` を導入（`spark` = 加算合成の火花 / `smoke` = 煙 / 既定 = 絵文字）、
  `grav`・`decay` も粒子ごとに指定可能に。上限は600→900個
- 設定パネルに「ロケット」ON/OFF を追加。OFF時は従来どおりの紙吹雪のみのお祝い
- `prefers-reduced-motion` 指定時はシェイク・フラッシュ・炎の揺らぎ・跳ねを停止し、粒子数も削減

### 内部構造の変更

- 弁当箱の埋まり具合を `bites`（累計）から独立させ `filled`（0〜6）で管理。
  発射シーケンス中にひとくち検知が入ってもマスの番号がずれないようにした
- `launching` フラグを追加。シーケンス中の追加検知はカウントと歓声のみ反映
- 「さいしょから」で `clearSeq()` を呼び、進行中のシーケンスとタイマーを確実に停止
- レイアウト用に CSS 変数 `--deck:118px`（弁当箱の上端）を追加し、
  ボタン・ロケット・設定パネルの縦位置をこれに揃えた
